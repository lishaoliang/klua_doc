## 名称限制与字符集 (Name Limits and Character Sets)

### 短目录项 (Short Directory Entries)

**短文件名 (short name)** 最多 8 个字符, 后可跟可选句点 (`.`) 与最多 3 字符扩展名. 短名 **完整路径** (含尾部 NUL) 不得超过 80 字符 (64 字符路径 + 3 驱动器字母 + 12 用于 8.3 名 + NUL).

字符可为字母、数字或码点大于 127 的字符. 还允许下列特殊字符:

```
$   %   '   -   _   @   ~   `   !   (   )   {   }   ^   #   &
```

名称以创建目录项时系统配置的 **OEM 代码页** 存入短目录项. 短目录项保持 OEM 以兼容旧版 MS-DOS/Windows. OEM 字符为单字节 8 位, 或在部分代码页为 DBCS 双字节对.

传入文件系统的短名 **一律转大写**, 原始大小写丢失. 多数 OEM 代码页将扩展字符小写映射到大写时 **非一一对应** — 多个扩展字符映射到同一大写字符, 丢失信息, 并阻止创建本可区分、转大写后却相同的文件名.

### 长目录项 (Long Directory Entries)

**长文件名 (long name / LFN)** 最多 255 字符 (不含尾部 NUL). 长名完整路径 (含尾部 NUL) 不得超过 **260** 字符.

字符集合在短名基础上允许句点 (`.`) **多次出现**. 空格合法 (短名中亦合法, 但短名中较少使用). 下列六个字符 **仅** 允许于长名, 短名中 **非法**:

```
+   ,   ;   =   [   ]
```

长名 **中间** 可含空格; **首尾** 空格忽略.

长名 **前导与中间** 句点保留; **尾部** 句点忽略.

长名存入 **LDIR_*** 长目录项, 编码为 **UNICODE** (16 位字符). 短目录项无法存 UNICODE, 其中仅为 8 位或 DBCS.

传入文件系统的长名 **不** 转大写, **保留** 原始大小写. UNICODE 将小写映射到唯一大写, 避免部分 OEM 代码页的歧义.
