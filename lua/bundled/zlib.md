# zlib (lua-zlib)

> 类别: ② bundled | `require("zlib")` | 代码: `klb/src_c/klua/lua-zlib-1.3/`

lua-zlib: zlib 压缩/解压 Lua 绑定 (链 klb `zlib-1.2.11`).

## 加载

```lua
local zlib = require("zlib")
```

## klb 注意

- 裁剪: `__KLB_NO_ZLIB__` (`no-zlib`)
- 与 klb 根级 `zlib-1.2.11/` vendor 不同路径, 勿混
