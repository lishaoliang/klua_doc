# 标签约定

> `klua_doc/_meta/tags.md`

手写笔记 frontmatter 可选字段见下. 生成物 (`api/_gen/`) 使用 `generated: true`.

## type

| 值 | 含义 |
|----|------|
| `note` | 个人理解/归纳 |
| `api` | API 说明 |
| `spec-mirror` | 规范镜像章节 |
| `test` | 自测用例文档 |
| `tool` | CLI/工具说明 |

## status

| 值 | 含义 |
|----|------|
| `draft` | 草稿 |
| `active` | 现行 |
| `archived` | 归档 |

## project

`klb` | `pfs` | `lua` | `misc`
